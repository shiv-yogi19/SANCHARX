How this was measured
  • Latency: 10 repeated tiny HTTP requests; the median is shown. This is HTTP latency, not ICMP ping.
  • Jitter: the average difference between consecutive latency samples. An estimate, not a carrier-grade measure.
  • Download: real data streamed from speed.cloudflare.com in growing steps; bytes counted as they arrive.
  • Upload: randomly generated data posted to speed.cloudflare.com. No personal files are ever uploaded.
  • Packet loss is not measured, because a browser cannot count lost packets reliably.

DNS Lookup

Uses a public DNS-over-HTTPS resolver you choose. Results can differ from your router or provider because of caching and resolver behavior. Your private DNS settings are not visible to a web page.

Public IP Lookup

This contacts the external service ipify.org, which sees your public IP address in order to return it. Nothing is stored or sent anywhere else by SANCHARX. No location is looked up.

HTTP Endpoint Latency Checker

Measures how long a site takes to respond, using 3 requests. Browser security (CORS) hides the response, so only reachability and timing are known. A failed check is not proof that the site is down.

Gaming & Streaming Advisor

Estimates from your latest measured values only. Real experience also depends on the service, your device, Wi-Fi conditions, server distance, congestion and other people using your connection. Nothing here is a guarantee.

Network Safety Guide

Educational guidance only. SANCHARX does not scan networks or devices.
