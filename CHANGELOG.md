# Changelog
## 1.0.0 — initial release (built from scratch; no source project was supplied)
- Real browser speed test engine (latency, jitter, download, upload) with cancel/retry, overlap protection, Save-Data cap, honest failure states.
- Network tools: Stability Monitor, Troubleshooter (10 playbooks), Data Calculator, IPv4/Subnet, DNS-over-HTTPS, Public IP, Endpoint checker, Gaming & Streaming advisor, Safety guide.
- History, comparison, trends; branded print-to-PDF report.
- Rule-based assistant, exactly 50 bilingual FAQs; English/Hindi UI.
- Obsidian Aurora + Liquid Glass design, intro, 25 animation patterns, reduced-motion support, responsive desktop/mobile layouts.
- Out of scope and not included: QR Studio, Image Editing Studio, PDF editing tools.
- Fix found in testing: every measured step now yields at least one real graph sample, even on very fast links.
